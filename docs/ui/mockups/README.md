# DMI-131 mockups

- `dmi-131-mockups-v4.html` — the full-screen mockups, **approved 2026-09-02**. The visual exemplar for every screen in DMI-132.
- `dmi-131-look-picker.html` — the token/look comparison page that settled the foundations in §4.
- `dmi-131-screen-map.html` — the screen map: every screen, its epicenter, its actions, its content.

All three are static HTML with no build step; they pull their faces from Google Fonts, so open them online.
The look picker and the screen map are historical inputs — parts of them were superseded by later reviews.
Where they disagree with `../DESIGN-SYSTEM-RESEARCH.md`, the research note is authoritative.
