Urgency: how findings are categorised

The open one

The owner is not an engineer — “High” is our word, not theirs — and a chip beside every row asks them to read six labels and compare them before they know what to do first. The three patterns below carry the same six findings, so only the pattern changes.

The heading carries the urgency, so each row is just the sentence. Three headings to read instead of six labels, and the order on the page is the order to work in. The empty state is the same object, so “all clear” looks deliberate, not blank.

Lighter: one card, spacing alone separates the groups. The icon repeats the colour so the meaning does not rest on hue. Weaker when a group is long — the heading scrolls away and the rows lose their label.

The shortest to scan and the hardest to learn: the bar means nothing until someone explains it, and colour alone fails for a colour-blind reader. Shown so it can be rejected on sight rather than in the abstract.

The system defines the three group names, their colours, their order and the all-clear state — a screen never invents a fourth group or renames one.
The screen decides which finding lands in which group, and what the row says.
